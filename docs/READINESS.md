# สถานะการพัฒนา — 7 กันยายน 2026

## ใช้ทดลองในเครื่องได้
- อ่านดาว 6 กลุ่ม สุ่มไม่ซ้ำในชุด แยกข้อความทีม/ชุมชน
- เขียน/ดูตัวอย่าง/พับ 4 ช่วง/ส่งดาว อ่านดาวที่เพิ่งส่งและพัก animation ขณะเปิดอ่าน
- โถดาว บันทึกไม่ซ้ำ รายการดาวทั้งหมด และประวัติการเขียนแยกกัน
- ผู้เยี่ยมชมส่งข้อความได้ ข้อความไม่ถูกนำเข้าประวัติเมื่อลงชื่อเข้าใช้ภายหลัง
- บัญชีทดลองชัดเจนสำหรับทดสอบโถและหน้าตรวจข้อความ
- ข้อความใหม่รอการตรวจ ผู้ส่งเห็นว่าส่งแล้วโดยไม่อ้างว่ามีคนอ่าน
- ซ่อนข้อความจาก pool และรายการที่เคยบันทึก ตรวจสถานะใหม่ก่อนเปิดดาว
- Layout มือถือ/แท็บเล็ต/เดสก์ท็อป, dialog รองรับ keyboard/Escape, reduced motion
- ข้อความทีมร่าง 60 ข้อความใช้ใน preview เท่านั้น

## ยังไม่ถือว่าพร้อมเปิดสาธารณะ
1. พักการลงชื่อเข้าใช้ Google และอีเมลตามคำขอ ต้องกลับมาตั้ง provider/session และทดสอบสิทธิ์ข้ามบัญชีจริงก่อนเปิดโถส่วนตัว
2. เตรียม SQL และ Edge Function แล้ว แต่ยังไม่ได้ติดตั้งหรือทดสอบบน Supabase จริง
3. ต้องต่อ Turnstile ฝั่งหน้าเว็บให้ส่ง token จริง ขณะนี้ Edge Function ปฏิเสธการส่ง/รายงานที่ไม่มี token ห้ามปิดการตรวจเพื่อให้ผ่าน
4. ผู้ใช้ต้องตรวจร่างข้อความทีม 60 ข้อความก่อนอนุมัติลง pool จริง
5. ตรวจ migration และ RLS ด้วยฐานข้อมูลทดสอบ: guest/member/moderator, concurrent duplicate requests, revoked JWT, hidden saved content, rollback
6. ตรวจ animation เทียบ prototype ด้วยสายตาทั้งระยะเวลาและตำแหน่ง โดยเฉพาะดาวเข้าปากโถและการบังขอบแก้ว; browser flow test ใช้ reduced motion จึงไม่ยืนยันความตรงของ motion
7. ร่างข้อความยังไม่กู้คืนหลัง refresh และ navigation ยังไม่เก็บประวัติทุกหน้าของเบราว์เซอร์
8. ขณะเปิดข้อความค้างไว้ การซ่อนจากอุปกรณ์อื่นยังไม่ผลักสถานะทันที ต้องเพิ่ม realtime/revalidation เมื่อกลับโฟกัส
9. หน้าคิวจริงจำกัด 500 รายการ ต้องเพิ่ม pagination และค้นหาก่อนใช้กับข้อมูลมาก
10. เตรียม Privacy/Terms, ช่องทางติดต่อผู้ดูแล, นโยบายเก็บ/ลบข้อมูล, แผนรับเรื่องร้องเรียนและเวรตรวจข้อความ ไม่มีการตรวจต่อเนื่องอัตโนมัติ
11. ตั้ง GitHub/Cloudflare, โดเมนจริง, environment variables, allowed origins, monitoring, backup/restore และทดสอบ staging ก่อนเปิด public
