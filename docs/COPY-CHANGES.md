## ผลตรวจหลังปรับภาษา

- Production build ผ่าน โดยยังมีคำเตือนขนาด bundle เดิม
- การทดสอบข้อมูลผ่าน 4 รายการ รวมการอัปเดตข้อความทีมในดาวที่เคยเก็บไว้ โดยคงรหัสดาวและสถานะการตรวจ ไม่แก้เนื้อหาชุมชน
- Chrome ผ่าน 15 รายการ ครอบคลุม 320/390/834/1280 px, อ่าน/เขียน/ส่ง/เก็บ, ข้อความยาว, รายงาน, ข้อผิดพลาดดาวที่เปิดไม่ได้ และ animation เดิม
- ตรวจภาพหน้าแรกจอ 320 และหน้าตัวอย่างจอ 390 ด้วยสายตา ข้อความไม่ล้น
- ตรวจคำเดิมแบบตรงตัวในส่วนที่แก้ ไม่พบตกหล่น
- ดาวทีมทั้ง 60 ข้อความยาวสูงสุด 59 Unicode code points (ไม่เกิน 120)
- ยังเป็นการทดสอบในเครื่อง ข้อความแจ้งเตือนฝั่ง Supabase เปลี่ยนใน source เท่านั้น ยังไม่ deploy และไม่เปิดเผยแพร่ข้อความทีมอัตโนมัติ
