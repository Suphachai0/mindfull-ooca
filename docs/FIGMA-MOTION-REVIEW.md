# OOCA — เวอร์ชันตรวจ Figma และ Motion

Branch: `codex/figma-motion-review` · 8 กันยายน 2026

เวอร์ชันนี้ยังไม่ merge, push หรือ deploy เว็บไซต์จริง ใช้ข้อมูลทดลองในเบราว์เซอร์ ไม่ใช่ผลทดสอบระบบ production

## รายการปรับจากเว็บเดิม

- Home: ปรับข้อความตามแบบ นำรูปไอคอนกล้องออกจากปุ่มเริ่ม เพิ่มอูก้าลอยขึ้นลง 8 px / 6 วินาที และเมฆเคลื่อนซ้ายไปขวารอบละ 12 วินาที
- Emotional Need: ใช้ฉากเมฆและดาวเวกเตอร์จาก Figma แยกพื้นหลังที่ติดมากับไฟล์ export ออก ดาวลอยขึ้นและจางหายรอบละ 7.2 วินาที เหลื่อมกัน 0.8 วินาที เลือกแล้วหยุดดาวเพื่อยืนยันหรือยกเลิก
- Save: เปลี่ยนหน้าด้วย fade 0.4 วินาที ดาวลอยเข้ามา 1.2 วินาที แล้วเปลี่ยนภาพคลี่กระดาษทีละขั้น 0.9 วินาที ปุ่มใช้งานปรากฏเมื่อคลี่ครบ
- Write: ตัวเลือกอารมณ์ 3×2 ช่องเขียนสูง 180 px และปรับข้อความ/ปุ่มตามแบบ
- Fold: เปลี่ยนภาพพับตามขั้น จบภายใน 6 วินาที ข้อความจางและดาวออกด้านบนช่วงท้าย
- Success: ดาวอื่น 5 ดวงและดาวของผู้ใช้ที่เน้นขอบขาว ลอยเบา ๆ และเปิดอ่านข้อความได้ ไม่หายจากพื้นที่กดก่อนเปิดอ่าน
- Popup: ฉากหลังมืด กระดาษดาวพร้อมข้อความ ปิดด้วยปุ่มหรือ Escape และคืนตำแหน่งโฟกัสไปที่ดาว
- รองรับ reduced motion: หยุดฉากตกแต่งและย่นลำดับการเปลี่ยนภาพ

ยังเก็บตัวช่วยสุ่มดาว ข้อความแจ้งการใช้งานแบบผู้เยี่ยมชม การบันทึก การรายงานข้อความ captcha และการตรวจข้อความของระบบเดิม ไม่ได้เปลี่ยน API หรือฐานข้อมูล

## ข้อจำกัดที่ต้องตรวจรับก่อน deploy

- ยังไม่ยืนยันความเหมือนระดับพิกเซลทุกเฟรม และยังไม่ได้ทดสอบ Safari/Firefox
- การพับใช้ภาพนิ่งเปลี่ยนด้วย crossfade ไม่ใช่กระดาษ 3D บิดจริง
- ภาพกระดาษคลี่เดิมเป็น PNG 250 px ใช้ขอบตัดในหน้าเว็บเพื่อตัดพื้นขาว จึงควรตรวจความคมและขอบของทุกสีบนอุปกรณ์จริงก่อนอนุมัติ
- ดาวในฉาก Success ใช้รูปเวกเตอร์สีตาม Figma ส่วนกระดาษที่เปิดยังใช้สีจากไฟล์ของอารมณ์เดิม
- Build มีคำเตือน JavaScript bundle ประมาณ 586 kB ควรแบ่งโหลดในการปรับประสิทธิภาพรอบถัดไป

## Motion เพิ่มเติมที่เสนอ (ยังไม่ได้เพิ่ม)

- ปุ่มยุบเบา ๆ เมื่อแตะ เพื่อสื่อว่ารับการกดแล้ว
- สถานะบันทึกสำเร็จเปลี่ยนเป็นเครื่องหมายถูกด้วย fade สั้น ๆ
- ลดการเคลื่อนไหวตกแต่งขณะพิมพ์ เพื่อให้จดจ่อกับข้อความ

ไม่แนะนำเพิ่มอนุภาคหรือแสงกระพริบต่อเนื่อง เพราะอาจรบกวนการอ่านและบรรยากาศสงบของโปรเจ็กต์
